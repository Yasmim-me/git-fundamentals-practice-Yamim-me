# Git workflow reflection

Write at least one complete sentence for each answer. Each answer must contain at least 20 characters.

## 1. What is the difference between a commit and a push?

Answer: commit makes changes directly on the computer, and when we hit push it uploads the saved commits to GitHub 
so other members can access

## 2. Why work on a branch instead of directly on `main`?

Answer: you can make tests and add new code, make changes without touching the main branch which 
has the original version that WORKS

## 3. What does a pull request make possible?

Answer: so other members of the team can visualize changes on the code, compare, discuss 
and review it before merging to the main branch

## 4. Which Git command helped you understand the repository's state, and what did it show you?

Answer: it helps to understand the repository by showing what is on the main branch with clean work on it
